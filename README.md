🐱 Cat Photo Gallery

Welcome to **CatPhotoGallery** – a simple, fun, and purr-fectly adorable project built using only HTML and CSS. This website is a tribute to our cat-loving friends and is designed to showcase a collection of cat images.

---

## 📸 Features

- A **gallery of 9 cat photos**, including:
  - 💤 A sleeping cat  
  - 🛋️ A cat lying on its back  
  - 🛏️ A cat under the duvet  
  - 👁️ A deep staring cat  
  - 👀 Two staring cats  
  - 🐾 A cat staring under the duvet  
  - 🤎 A brown cat lying on a sofa  
  - 🤎 A brown cat lying on a brown cat  

- 🎨 Styled using clean and responsive CSS for a user-friendly experience
